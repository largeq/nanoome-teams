# 나눔교실 팀 배정 · 웹 버전

봉사자의 지망을 받아 프로그램별 정원에 맞게 팀을 배정하는 브라우저 도구입니다.
Mac과 Windows의 최신 브라우저에서 사용할 수 있도록 제작했습니다.

**[나눔교실 팀 배정 열기](https://largeq.github.io/nanoome-teams/)**

## 이용 조건

비상업적인 목적으로 무료로 사용, 수정, 재배포할 수 있습니다.
자체 비상업적 이용 허가서를 적용하며, 복제·배포 시 저작권 표시와 이용 조건을 유지해야 합니다.

기업의 영리 업무, 유료 학원 운영, 재판매, 유료 서비스 제공 등 상업적 이용은 사전 서면 허가 없이 허용하지 않습니다.
이용료를 직접 받지 않는 기업 내부의 영리 업무 활용도 여기에 포함합니다.
교육기관이나 비영리 단체의 수익사업도 자동으로 허용되지 않습니다.

정확한 조건은 [LICENSE.txt](LICENSE.txt)를 확인해 주세요.

## 사용하기

1. **프로그램 설정**에서 프로그램 이름, 정원, 지망 수를 정합니다. 기본값은 국어·수학·영어·사탐·과탐 각 4명, 총 20명입니다.
2. **나누미 입력**에서 이름과 지망을 입력합니다. CSV 불러오기와 엑셀 표 붙여넣기도 가능합니다.
3. **배정 실행**을 누릅니다.
4. **배정 결과**에서 프로그램별 팀과 개인별 결과를 확인하고 CSV 또는 인쇄 대화상자의 PDF 저장으로 보관합니다.

지원 인원은 1~30명이며 전체 정원과 명단 인원은 같아야 합니다.
1지망은 필수이고 나머지는 선택입니다. 지망은 서로 다른 프로그램이어야 합니다.

## 배정 기준

헝가리안 알고리즘으로 배정 비용 합을 최소화합니다.

- 1지망: 0
- 2지망: 1
- 3지망: 2 (3지망 모드에서만)
- 미지망: 10

프로그램을 정원만큼의 자리로 펼쳐 한 사람을 한 자리에 배정합니다.
전체 비용 합을 최소화하므로 모든 사람의 1지망, 1지망 인원 최대화, 미지망 인원 최소화를 각각 별도로 보장하지는 않습니다.
최적 조합이 여럿이면 입력 순서와 프로그램 순서에 따라 그중 하나를 선택합니다.
현재 전공이나 경력은 배정 계산에 반영하지 않습니다.

## 명단 파일

UTF-8 CSV 파일의 기본 열은 `이름,1지망,2지망`입니다. 3지망 모드에서는 `3지망` 열을 추가합니다.
`공부법 1지망`, `공부법 2지망` 등의 제목도 읽을 수 있습니다.
제목이 없는 파일은 이름·1지망·2지망·3지망 순서로 읽습니다.
프로그램명은 현재 설정과 같아야 합니다.

CSV는 UTF-8 BOM을 포함해 저장합니다. 이름이나 프로그램명이 수식으로 해석될 수 있는 기호로 시작하면 스프레드시트에서 실행되지 않도록 작은따옴표를 앞에 붙입니다.

## 내 정보는 어디에 있나요?

명단과 배정 계산은 브라우저에서 처리하며 명단을 서버에 전송하지 않습니다.
외부 폰트·분석 도구·런타임 CDN을 사용하지 않습니다.
설정과 입력은 해당 브라우저의 로컬 저장소에 저장합니다. 브라우저 데이터 삭제나 다른 브라우저 사용 시 유지되지 않으므로 중요한 명단은 CSV로 저장해 주세요.
웹 호스팅 제공자는 사이트 접속에 관한 로그를 별도로 수집할 수 있습니다.

## 개발 및 미리보기

Node.js 22 이상을 사용합니다. 외부 패키지 설치는 필요하지 않습니다.

```sh
npm run dev
```

출력된 `http://127.0.0.1:4173/` 주소를 브라우저에서 엽니다.
모듈을 사용하므로 HTML 파일을 더블클릭하는 대신 로컬 서버 또는 웹사이트 주소로 접속해 주세요.

```sh
npm test
npm run build
```

`dist/`가 실제 배포 파일입니다. 다른 정적 웹 호스팅에서도 이 폴더를 게시할 수 있습니다.
소스 코드뿐 아니라 배포 시점의 `dist/`도 별도로 보관하면 장기 보존에 도움이 됩니다.

## GitHub Pages

GitHub Actions를 통해 배포합니다. `main`에 코드를 올리면 웹사이트도 자동으로 갱신됩니다.
배포 설정은 `.github/workflows/pages.yml`에 있으며, 이용 허가서도 배포 파일에 포함합니다.

1. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 선택합니다.
2. `main`에 코드를 올리거나 **Actions → Publish web app to GitHub Pages → Run workflow**에서 수동으로 실행합니다.
3. 배포 작업이 완료되면 표시되는 Pages 주소로 접속합니다.
